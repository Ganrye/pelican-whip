# 鹈鹕快鞭

一只鹈鹕骑自行车，不蹬踏板，全靠挥鞭加速的小游戏。

## 玩法

- 点击画面、按空格键，或点「挥鞭！」按钮挥鞭加速。
- 在节奏条的绿色区间（上一鞭后 0.5 到 1.2 秒）内挥鞭可以叠连击，每层多 20% 加速，最高 ×2。
- 可以调整鞭力、路面（柏油路 / 沙地 / 冰面）、时段（白天 / 黄昏 / 夜晚）、车身颜色，以及自动挥鞭和音效。

## 技术

单个 `index.html` 文件，不依赖任何框架或构建工具：

- HTML + CSS：页面布局和控件，支持浅色 / 深色模式和手机屏幕
- Canvas 2D：逐帧绘制场景和角色，用 `Path2D` 直接复用 SVG 路径
- 原生 JavaScript：物理（速度、阻力）、动画、连击判定
- Web Audio API：实时合成挥鞭的“啪”声
- localStorage：记住设置和历史最高时速

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 在线访问（GitHub Pages）

仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后几分钟即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
